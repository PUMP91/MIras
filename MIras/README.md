# Miras — Учёные Ислама

Сайт с биографиями и Telegram Mini App для [@UlamaInfoBot](https://t.me/UlamaInfoBot).
Статические HTML, CSS и JavaScript; установка библиотек и сборка не требуются.

## Публикация на GitHub Pages

Репозиторий: https://github.com/PUMP91/MIras

1. Загрузить файлы сайта в корень репозитория: `index.html` должен лежать рядом с папками `Category`, `biografy` и `img`.
2. Открыть **Settings → Pages**.
3. В **Source** выбрать **Deploy from a branch**.
4. Выбрать ветку **main**, папку **/ (root)** и нажать **Save**.
5. Дождаться успешной публикации. Ожидаемый адрес: https://pump91.github.io/MIras/

Адрес чувствителен к регистру: папка проекта называется `MIras`.
Свой домен и платный сервер для чтения биографий не нужны.

## Подключение к Telegram

После того как опубликованный сайт открывается по HTTPS:

1. Открыть [@BotFather](https://t.me/BotFather), отправить `/mybots` и выбрать `@UlamaInfoBot`.
2. В настройках бота открыть **Bot Settings → Configure Mini App → Enable Mini App** и указать опубликованный адрес сайта. Названия пунктов могут отличаться между версиями интерфейса BotFather.
3. Для кнопки в чате отправить `/setmenubutton`, выбрать `@UlamaInfoBot`, указать тот же адрес и подпись **Открыть Miras**, следуя подсказкам BotFather.
4. Открыть https://t.me/UlamaInfoBot?startapp и проверить запуск.

Токен бота не используется в файлах сайта и не нужен для этих настроек через BotFather.
В этой версии бот открывает библиотеку; автоматические ответы на сообщения и `/start` требуют отдельной серверной логики.

## Что проверить после запуска

- Главную страницу, все четыре категории и четыре опубликованные биографии.
- Нижние вкладки «Главная», «Учёные», «Категории» и кнопку «Назад» Telegram.
- Светлую и тёмную темы Telegram, прокрутку длинных страниц.
- Открытие на Android, iOS и компьютере. Браузерная проверка не заменяет проверку на устройствах.

Нижняя панель отображается на узких экранах и внутри Telegram. Обычный настольный браузер сохраняет верхнее меню.
Без Telegram сайт работает как обычный сайт; регистрация читателя не требуется.

Документация: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
